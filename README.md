# Telegram Bot — Крестики-Нолики

Бот для игры в крестики-нолики прямо в Telegram. Игроки делают ходы нажимая на кнопки под игровым полем.

---

## Установка

```bash
pip install -r requirements.txt
```

---

## Настройка бота

1. Откройте [BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте токен вашего бота
4. Замените `YOUR_BOT_TOKEN` в файле `bot.py` на ваш реальный токен

```python
# bot.py, строка ~11
bot = Bot(token="ВАШ_ТОКЕН_ЗДЕСЬ")
```

---

## Запуск

```bash
python bot.py
```

После запуска отправьте боту сообщение `/start` и затем `/new` чтобы начать игру!

---

## Структура проекта

- **`bot.py`** — основной код Telegram бота (aiogram 3.x)
- **`game.py`** — логика игры крестики-нолики
- **`requirements.txt`** — зависимости Python
- **`README.md`** — этот файл

---

## Возможности

- Интерактивный интерфейс с inline кнопками
- Красивое отображение поля с эмодзи
- Поддержка нескольких параллельных игр (каждый игрок в своём чате)
- Команды `/start`, `/help`, `/new`
- Автоматическое определение победителя и ничьей

---

## Технологии

- **Python 3.10+**
- **aiogram 3.x** — современный асинхронный фреймворк для Telegram ботов
